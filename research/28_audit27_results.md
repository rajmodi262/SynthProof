## Correction: a fair 'before' for Adult, Bank, ACS and Diabetes

The archived grids for these four datasets predate the evaluator fix that one-hot encodes categorical
features, so their 'before' numbers above were scored with a different yardstick (numeric features
only) and are NOT comparable. The rows below re-measure the PRE-FIX code (commit c9336e8) on the same
split and seed with TODAY's evaluator (unseen-row usefulness). Seed 0 only. Source:
results/fair_before.log (sp_old worktree, `fair_before.py`).

| Dataset | AIM ε=1 old → new | AIM ε=8 old → new | MST ε=1 old → new | MST ε=8 old → new |
|---|---|---|---|---|
| adult | 81% → **97%** | 81% → **94%** | 82% → **82%** | 81% → **84%** |
| bank | 81% → **97%** | 77% → **97%** | 80% → **85%** | 79% → **77%** |
| acs | 84% → **100%** | 62% → **99%** | 94% → **95%** | 94% → **95%** |
| diabetes | 99% → **98%** | 99% → **98%** | 99% → **98%** | 99% → **99%** |

**What this changes.** The AIM gains hold on Adult, Bank and ACS measured fairly. Diabetes shows no gain
(it was already ~99%). The 'MST regression on Bank' in the table above was an artefact of the mismatched
yardstick: the old MST scores ~79-80% on Bank when measured the same way, level with the new MST
(~81%, 3 seeds at ε=8). The old code also proved only 0.75-0.78 of ε=1 and 6.2-6.6 of ε=8; the new code
proves the full target. The Texas, Fire, Wine, Breast Cancer, German, Mushroom and Nursery 'before'
numbers above were produced after the evaluator fix and are comparable as they stand.
